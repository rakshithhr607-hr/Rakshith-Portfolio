# Personal Portfolio Website

A full-stack personal portfolio website developed to showcase my technical skills, projects, education, and professional journey.

The application features a modern and responsive user interface along with an integrated admin dashboard that allows dynamic management of portfolio content.

### Key Features
- Responsive portfolio website.
- About Me, Skills, Education and Experience sections.
- Project showcase with GitHub and live demo links.
- Contact form.
- Admin dashboard for content management.
- Backend API and MongoDB database integration.

### Technologies Used
- **Frontend:** React.js, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas, Mongoose
- **Authentication:** JWT, Bcrypt.js
- **Deployment:** Cloudflare Pages and Render
